Google Sheet Setup Instructions

Create a Google Sheet with pre-filled Type column. Students only fill in Name and predictions (R/N):

Type Name A B C ... L
Student John Smith R N R ... N
Student Jane Doe R R N ... R
Student (empty rows...)
AI ChatGPT (John) R R N ... R
AI Claude (Jane) N R N ... N
AI (empty rows...)
  • Type: Pre-fill with "Student" rows, then "AI" rows below (protect this column)
  • Name: Students fill in their name; for AI, include model + name (e.g., "Claude (Jane)")
  • A-L: "R" = Recession, "N" = No Recession
  • Tip: Create ~30 Student rows and ~30 AI rows. Empty rows are ignored.
